# Article / Project Digest

User-layer proof-point digest for Career-Ops. Keep this evidence-backed; do not invent adoption, revenue, benchmark, or user-count metrics.

## Positioning

Clayton Bivens builds AI systems, developer tooling, and local-first automation around orchestration, runbooks, diagnostics, and operator control. The strongest framing is not generic "AI engineer" hype; it is practical systems work: make state visible, keep workflows recoverable, and design tools that help real operators move faster without losing control.

## Core Proof Themes

- **Serena Pack**: repo-owned workflow pack and control-plane CLI for project readiness, state repair, and handoff discipline.
- **ABOps**: deterministic orchestration engine for replayable agent workflows, immutable artifacts, and operator-facing control.
- **Oracle Pack**: Markdown-native operational pack runner with validation, resumable state, and traceable execution.

Use when applying for:

- AI Systems Engineer

### 2. Local-first and privacy-aware tooling

Use when applying for:

- Developer tooling roles

- Automation engineering roles

- Improved repair cycle time by about 30% through shop layout and workflow optimization.

Use when applying for:
